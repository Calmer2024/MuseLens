# v4.1

###  架构核心理念：双轨制 (Dual-Track) 路由

在 v4.1 架构下，LLM 智能路由器将根据用户的“物理保真度要求”，动态将 DAG 任务分发到两条轨道：

- **🛤️ 轨道 A（工业级****像素****管控流）：** 面向电商、UI 设计。死保核心像素（Logo/文字），放开边缘进行差分融合，辅以物理阴影生成，追求 **100% 商业保真**。
- **🛤️ 轨道 B（影视级特征重构流）：** 面向人像、摄影、创意合成。**摒弃遮罩 (Mask)**，提取原图的结构与身份特征强行注入大模型，追求 **极致的光影融合与氛围感**。

## 一、 A1-A5 原子透镜全景字典 (v4.1 完全体)

### 👁️ A1: 视觉解析层 (Vision Parser)

*不产生新画面，专门负责提取物理特征与身份信息，作为下游生成引擎的“约束锚点”。*

| Lens ID                | 名称         | 核心功能                                                     | Inputs 资产 | Outputs 资产         | 底层节点技术                |
| ---------------------- | ------------ | ------------------------------------------------------------ | ----------- | -------------------- | --------------------------- |
| lens_mask_core         | 核心遮罩提取 | 语义抠图后向内腐蚀像素，仅提取物体最中心的绝对保护区，抛弃生硬边缘。 | BASE_IMAGE  | CORE_MASK            | SAM2 + Mask Erode           |
| lens_structure_extract | 物理骨架提取 | 提取画面的 3D 深度图和边缘线稿，作为下游重绘的空间与轮廓约束。 | BASE_IMAGE  | DEPTH_MAP, CANNY_MAP | DepthAnythingV2, Canny Edge |
| lens_pose_extract      | 姿态骨骼提取 | 提取人物的关节点数据，用于严格锁定重绘时的主体动作。         | BASE_IMAGE  | POSE_MAP             | DWPose / OpenPose           |
| lens_identity_extract  | 身份特征提取 | 提取原图主体（人脸/衣服）的高维向量特征，用于无遮罩重绘时的身份锁定。 | BASE_IMAGE  | IDENTITY_EMBED       | CLIP Vision / FaceID        |

## 二、 DAG 调度引擎高频场景实战 (LLM 路由决策)

当用户输入自然语言需求时，后端的 LLM 将智能组装透镜，生成标准的 JSON 编排计划。

###  场景 1：电商高级商品图合成 (触发 轨道 A)

- **用户输入：** “把这款带有品牌 Logo 的神仙水放到黑色火山岩上，Logo 绝对不能变形，需要有真实的倒影。”
- **系统判定：** 包含核心商业资产，必须执行绝对的像素管控。
- **DAG** **执行流：**
  - **[A1]** **`lens_mask_core`****:** 抠出神仙水并向内腐蚀，产出 `CORE_MASK`（仅覆盖瓶身中心）。
  - **[A1]** **`lens_structure_extract`****:** 提取瓶子的 `DEPTH_MAP`，为后续倒影提供 3D 参考。
  - **[A2]** **`lens_inpaint_diff`****:** 结合 Prompt (黑色火山岩)。大模型自动融合瓶子边缘的环境光反射，消除剪纸感。
  - **[A3]** **`lens_shadow_cast`****:** 在瓶底生成极其真实的火山岩接触阴影。
  - **[A5]** **`lens_composite_core`****:** 将原图的 `CORE_MASK` 区域原封不动地贴回最顶层。**（交付底线：Logo 100% 完美）**。

###  场景 2：人像大片跨时空融合 (触发 轨道 B)

- **用户输入：** “把我这张在宿舍的自拍背景换成巴黎铁塔下的浪漫夜景，要完美融入。”
- **系统判定：** 跨环境转换，追求极致光影融合，允许衣服产生合理光照折射。废弃遮罩。
- **DAG** **执行流：**
  - **[A0]** **`lens_outpaint_expand`****:** (如果构图太紧) 先扩充画幅，为夜景留出空间。
  - **[A1]** **`lens_identity_extract`****:** 提取人脸与衣服的特征向量 `IDENTITY_EMBED`。
  - **[A1]** **`lens_structure_extract`****:** 提取 `DEPTH_MAP` 锁定人体体积。
  - **[A2]** **`lens_flux_reference`****:** 注入特征与深度，配合 Prompt (巴黎铁塔、夜景霓虹灯)。FLUX.2 进行无遮罩全局重绘，霓虹灯光极其自然地反射在头发和肩膀上。
  - **[A5]** **`lens_face_detailer`****:** 轻度精修五官，防止远景崩坏。**（交付底线：电影级光影质感）**。

###  场景 3：社交媒体“不换背景换次元” (触发 轨道 B 变体)

- **用户输入：** “把这张图里的人变成吉卜力动漫里的女主角，动作和背景里的沙发要保持一样。”
- **系统判定：** 结构强锁定，风格大转换。
- **DAG** **执行流：**
  - **[A1]** **`lens_pose_extract`****:** 提取人物的 `POSE_MAP`。
  - **[A1]** **`lens_structure_extract`****:** 提取沙发的 `CANNY_MAP` (线稿)。
  - **[A4]** **`lens_ipadapter_style`****:** 结合吉卜力风格图作为 `STYLE_REF`，同时挂载 A1 提取的姿态和线稿，进行全图风格转换。

###  场景 4：极速轻量化修复 (纯物理工具链)

- **用户输入：** “去掉照片右上角的垃圾桶，然后调成复古胶片色调。”
- **系统判定：** 极简需求，禁止动用重度生成模型（降本增效）。
- **DAG** **执行流：**
  - **[A2]** **`lens_lama_remove`****:** 毫秒级物理抹除垃圾桶。
  - **[A4]** **`lens_color_grade`****:** 叠加复古胶片 LUT 滤镜，直接出图。
