## 后端启动与环境变量配置指南

本文档汇总后端运行期会读取的环境变量（主要是 `MUSELENS_*`，以及编译器需要的 `COMFYUI_*`），并给出 `backend/.env` 的示例写法与启动步骤。

> 说明：代码里通过 `os.getenv(...)` 直接读取环境变量；项目本身不会自动从 `backend/.env` 加载。因此你需要在启动前把这些变量加载到系统环境里（见下文“如何加载 `.env`”）。

---

## 1. 数据库相关（`MUSELENS_DB_URL`）

- `MUSELENS_DB_URL`（可选）
  - 默认：SQLite（如果你不设置）
  - 你当前需求：请务必配置为 PostgreSQL（示例）：
    - PostgreSQL：`postgresql+psycopg://user:password@localhost:5432/muselens`

---

## 2. LLM Planner 相关（`planner_service.py`）

`PlannerService` 用于把用户意图编排成结构化 DAGBlueprint，来自环境变量：

- `MUSELENS_LLM_API_KEY`（必填）
  - OpenAI 兼容网关/服务的鉴权 Key
- `MUSELENS_LLM_MODEL`（必填）
  - 模型名，例如 `gpt-4.1-mini` / `gpt-4.1`（取决于你的网关）
- `MUSELENS_LLM_BASE_URL`（可选，默认 `https://api.openai.com/v1`）
  - OpenAI 兼容网关地址（例如你自建网关的 base url）
- `MUSELENS_LLM_TIMEOUT_S`（可选，默认 `30`）
  - 请求超时（秒）

补充：当未设置 `MUSELENS_LLM_API_KEY` 或 `MUSELENS_LLM_MODEL` 时，`PlannerService.plan()` 会在真正调用时抛出运行时错误。

---

## 3. Router / RAG 相关（`router_service.py` 与 lenses API）

在本指南的默认推荐方案中，Router 使用 pgvector（`PgVectorLensRAGClient`）；当启用 pgvector 时：

- `MUSELENS_RAG_BACKEND`（可选）
- 建议设置为：`pgvector`（使用 PostgreSQL + pgvector）
- `MUSELENS_PG_DSN`（当 `MUSELENS_RAG_BACKEND=pgvector` 时必填）
  - PostgreSQL 连接串，例如：`postgresql://user:password@localhost:5432/muselens`
- `MUSELENS_RAG_PGVECTOR_TABLE`（可选，默认 `lens_embeddings`）
  - 向量表名称

相关脚本：
- `POST /api/v1/lenses/register` 在检测到 `MUSELENS_RAG_BACKEND=pgvector` 时，会尝试同步该 lens 的向量（如果缺少 `MUSELENS_PG_DSN` 会跳过）。
- `python -m app.scripts.sync_lens_embeddings_cli` 会使用 `MUSELENS_PG_DSN` 与 `MUSELENS_RAG_PGVECTOR_TABLE` 同步全部 lens 向量。

---

## 4. ComfyUI 文件路径（编译器用到）

`MuseDNACompiler` 在运行时会访问：

- `COMFYUI_OUTPUT_DIR`（可选）
  - 默认：`E:\ComfyUI_windows_portable\ComfyUI\output`
  - 作用：从这里读取 ComfyUI 产物，再“搬运”到输入目录供后续 step 使用
- `COMFYUI_INPUT_DIR`（可选）
  - 默认：`E:\ComfyUI_windows_portable\ComfyUI\input`
  - 作用：作为下一步 ComfyUI 执行的输入目录

---

## 5. `backend/.env` 应该如何书写

建议使用如下格式：一行一个 `KEY=value`，不要在 `=` 两侧添加多余空格；值里如需包含特殊字符，尽量避免使用复杂引号（或自行确认 PowerShell 加载方式）。

示例（把其中的占位符替换成你自己的）：

```env
# ---------------- Database (PostgreSQL) ----------------
MUSELENS_DB_URL=postgresql+psycopg://user:password@localhost:5432/muselens

# ---------------- LLM Planner ----------------
MUSELENS_LLM_BASE_URL=https://api.openai.com/v1
MUSELENS_LLM_API_KEY=YOUR_KEY_HERE
MUSELENS_LLM_MODEL=gpt-4.1-mini
MUSELENS_LLM_TIMEOUT_S=30

# ---------------- RAG (optional) ----------------
# 默认使用 pgvector
MUSELENS_RAG_BACKEND=pgvector
MUSELENS_PG_DSN=postgresql://postgres:1234@localhost:5432/postgres
MUSELENS_RAG_PGVECTOR_TABLE=lens_embeddings

# ---------------- ComfyUI paths ----------------
COMFYUI_OUTPUT_DIR=E:\ComfyUI_windows_portable\ComfyUI\output
COMFYUI_INPUT_DIR=E:\ComfyUI_windows_portable\ComfyUI\input
```

> 注意：`backend/.env` 不要提交到 Git。

## 6. 如何加载 `.env` 并启动（Windows PowerShell）

方式 A：在启动前手动 export（推荐，最稳）

在 `backend/` 目录执行：

```powershell
cd D:\Repositories\MuseLens\backend

$env:MUSELENS_DB_URL="postgresql+psycopg://user:password@localhost:5432/muselens"
$env:MUSELENS_LLM_API_KEY="YOUR_KEY_HERE"
$env:MUSELENS_LLM_MODEL="gpt-4.1-mini"
$env:COMFYUI_OUTPUT_DIR="E:\ComfyUI_windows_portable\ComfyUI\output"
$env:COMFYUI_INPUT_DIR="E:\ComfyUI_windows_portable\ComfyUI\input"

$env:MUSELENS_RAG_BACKEND="pgvector"
$env:MUSELENS_PG_DSN="postgresql://postgres:1234@localhost:5432/postgres"
$env:MUSELENS_RAG_PGVECTOR_TABLE="lens_embeddings"

uvicorn app.main:app --reload --host 0.0.0.0 --port 8000
```

方式 B：用 PowerShell 脚本把 `backend/.env` 写入环境变量

```powershell
cd D:\Repositories\MuseLens\backend

Get-Content .env | ForEach-Object {
  $line = $_.Trim()
  if ($line -eq "" -or $line.StartsWith("#")) { return }
  if ($line -match "^\s*([^=]+?)\s*=\s*(.*)\s*$") {
    $name = $matches[1].Trim()
    $value = $matches[2].Trim()
    $env:$name = $value
  }
}

uvicorn app.main:app --reload --host 0.0.0.0 --port 8000
```
